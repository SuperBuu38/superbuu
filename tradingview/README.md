# Indicateurs TradingView

Indicateurs écrits en Pine Script v6.

## Utilisation

1. Ouvre un graphique sur TradingView.
2. En bas de l'écran, ouvre **Pine Editor**.
3. Colle le contenu d'un fichier `.pine`.
4. Clique sur **Add to chart**.

## Indicateurs

| Fichier | Description |
|---|---|
| `ema_cross_rsi.pine` | Croisement de deux EMA (9/21 par défaut) avec filtre RSI, flèches BUY/SELL et alertes. |
